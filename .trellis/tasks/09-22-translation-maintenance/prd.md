# PaperDict 翻译维护

## Goal

让 PaperDict 严格服务于英语论文到简体中文的翻译场景，并提供可靠、可验证、术语一致的划词与整页翻译体验。

## Requirements

- 中文或中英混合文本不得触发划词翻译卡片。
- 离线词典/术语查询与在线整页翻译必须在界面和行为上明确区分。
- 关闭在线翻译后不得请求公共或自定义在线引擎。
- 隐藏悬浮胶囊后，从设置重新打开应在当前页面立即出现。
- 支持用户 CSV/JSON 术语库，并对划词、整句和整页翻译生效。
- 提供通用学术与统计、计算机与 AI、材料与工程、医学与生命科学、经济与社会科学入门术语包。
- OpenAI 兼容 API 和 DeepL 必须真正可用，具有连接测试、参数校验和错误反馈。
- 用户明确选择的自定义引擎失败时严格报错，不得静默使用公共免费引擎。
- 翻译缓存必须按引擎配置和术语版本隔离。

## Acceptance Criteria

- [x] 选择任意包含中日韩统一表意文字的文本均不出现翻译卡片。
- [x] 本地术语或词典命中时断网可用，并准确标记来源。
- [x] 关闭在线翻译后，本地未命中与整页翻译均给出准确、非网络故障式提示。
- [x] 设置中的悬浮胶囊开关无需刷新即可控制当前页面胶囊。
- [x] 用户可导入、导出、查询、编辑和删除 CSV/JSON 术语。
- [x] 用户术语优先于内置包和在线译文，长术语优先于短术语。
- [x] 无用户术语时，通用术语包默认工作，其他领域包可按需启用。
- [x] OpenAI/DeepL 测试连接能区分成功、认证失败、限流、配置错误和超时。
- [x] 自定义引擎失败不会调用公共免费引擎。
- [x] 完整自动化测试与语法检查通过。

## Out of Scope

- 内置大型离线机器翻译模型。
- 覆盖所有专业学科的完整权威词库。
- 未经用户审核直接创建或提交 Pull Request。
