# 划词翻译悬浮查词工具 (Chrome/Edge 扩展)

## Goal

为用户在阅读英文学术论文（网页与 PDF）时提供便捷的“划词即翻”工具：鼠标选中生词即可快速显示中文释义、音标与发音，避免频繁切换词典窗口中断阅读思考。

## Requirements

* **运行环境与形态**：Chrome / Edge 等 Chromium 内核浏览器扩展（Manifest V3 标准），纯原生轻量化实现。
* **支持场景**：各类学术网页（arXiv、Google Scholar、IEEE、ACM、Nature、PubMed 等）及浏览器直接打开的本地与在线 PDF 论文。
* **交互体验**：
  * 划选或双击单词后，松开鼠标瞬间在单词旁毫秒级弹出悬浮释义卡片。
  * 点击网页任意空白处或按下 `Esc` 键，卡片自然关闭，不干扰阅读。
  * 智能防误触：纯数字、代码变量、非英文文本、超短字符不盲目弹窗。
* **查词核心能力（混合双模，免配置）**：
  * **单词/词组**：内置本地离线高频词库（包含音标、词性划分的中文释义），划选瞬间零延迟秒显，断网可用。
  * **长句/未收录词**：自动调用在线翻译引擎兜底提供流畅整句中文翻译。
  * **零配置**：开箱即用，无需用户注册申请任何 API Key。
* **论文阅读专享优化**：
  * 自动清洗 PDF 跨行连字符断词（例如将跨行的 `hypo-` 和 `thesis` 智能合并为 `hypothesis`）。
  * 自动去除换行符、多余回车和连续空格。
* **悬浮卡片功能**：
  * 单词标题、音标显示。
  * 朗读发音：点击小喇叭播放单词真人朗读（调用浏览器 Web Speech TTS）。
  * 词性精炼释义：名词、动词、形容词等分行清晰显示。
  * 快捷操作：支持一键复制释义/单词。
  * 扩展弹窗（Popup 面板）：提供开关控制（划词即弹开关、连字符优化开关），方便用户根据需要随时切换。

## Phase 2: 论文就地全文双语对照与全中文速读 (In-situ Bilingual & Full Chinese Reader)

针对赶时间、希望直接看中文论文的学生与研究人员，提供一键将整篇论文变为双语对照或纯中文的极速阅读能力。

### Phase 2 Requirements
* **悬浮阅读控制胶囊 (Bilingual Float Widget)**：
  * 常驻学术网页及内置阅读器界面（位置柔和不挡正文，支持拖拽或快捷键 `Alt+B` 展开/切换）。
  * 支持三种阅读视图模式：
    * **【双语对照】**：英文段落下方优雅插入浅灰色/淡蓝底色中文译文；
    * **【仅看中文】**：英文段落淡化或隐藏，呈现纯中文论文体验，阅读速度提升 3~5 倍；
    * **【还原英文】**：一键恢复原版英文排版。
* **学术公式与格式保护 (Formula & Structure Protection)**：
  * 自动识别与锁定 `<math>`、KaTeX、MathJax、`$公式$`，翻译时占位保护并在译文生成后精准回填，杜绝乱码。
* **学术智能降噪与按需翻译**：
  * 自动跳过参考文献（References/Bibliography）、页眉页脚、代码块，避免浪费算力与版面污染。
  * **视口懒加载 (Viewport IntersectionObserver)**：仅对用户当前浏览视口内及附近的段落进行翻译，随滚动条流式加载，零等待零卡顿。
* **内置 PDF 阅读器集成**：
  * 在 PaperDict PDF 阅读器工具栏新增“双语对照/纯中文”模式切换，针对 PDF.js 文本层段落进行聚类翻译与对照渲染。
* **Popup 弹窗控制增强**：
  * 弹窗内增加“全文双语阅读”快捷启动入口及默认阅读模式偏好设置。

## Definition of Done

* Chrome / Edge 扩展完整实现，支持开发者模式“加载已解压的扩展程序”直接使用
* 附带完整的高频词库和流畅的 Shadow DOM 样式隔离（防止被页面已有样式污染）
* 提供清晰的图文级安装和使用指南（特别是如何在 Edge/Chrome 中开启“允许访问文件网址”以便直接划词阅读本地 PDF）

## Technical Approach

1. **Manifest V3 架构**：
   * `manifest.json`：定义权限（`activeTab`, `storage`, `scripting`，以及匹配 `http://*/*`, `https://*/*`, `file:///*`）。
   * `content_scripts`：注入划词监听器、PDF 文本清洗器、悬浮气泡 UI。
   * **Shadow DOM 隔离**：悬浮卡片使用 Web Components / Shadow DOM 挂载，彻底杜绝宿主论文网站（如 IEEE、Nature 等）的 CSS 样式污染。
2. **本地离线词库**：
   * 采用经过压缩和索引优化的 JSON 字典（涵盖大学英语四六级、考研、GRE、TOEFL 等数万学术高频词汇），扩展启动时或首次查词时加载到内存 Map，查词复杂度 $O(1)$。
3. **在线翻译兜底**：
   * 针对多词句子或词典未收录词汇，后台 Service Worker 或 Content Script 自动异步请求免费翻译接口，卡片显示优雅加载状态后填充结果。
4. **PDF 优化算法**：
   * 正则匹配并清除词尾连字符与换行断词：`text.replace(/(\w+)-\s*\n\s*(\w+)/g, '$1$2').replace(/\s+/g, ' ')`。

## Decision (ADR-lite)

* **Context**：用户在阅读英文论文时遇到生词，频繁切换查词软件太麻烦，需要划选即显中文释义。
* **Decision**：采用 Chrome / Edge 浏览器扩展（MV3 标准），使用 Shadow DOM 封装悬浮窗，采用“离线学术词典 + 在线翻译兜底”的混合双模，划选即弹。
* **Consequences**：
  * 优点：无需配置 API Key，秒出释义，无界面样式冲突，完美支持学术网页与本地/在线 PDF。
  * 注意点：读取本地 PDF 需在扩展管理页面勾选“允许访问文件网址”开关，将在文档中重点标明。

## Out of Scope

* 涉及重型 GPU 服务器的复杂扫描版 PDF OCR 重新排版生成（当前聚焦于学术网页与 PDF.js 文本层的就地双语与中文速读）。
