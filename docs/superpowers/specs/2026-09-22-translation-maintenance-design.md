# PaperDict 翻译维护设计

## 目标

修复中文文本误触发、整页翻译与“离线词典”概念混淆、悬浮胶囊设置不能即时生效以及自定义在线引擎不可验证的问题，并加入可导入的用户术语库与内置领域术语包。

## 范围

1. 划词查询只接受英语源文本。包含中日韩统一表意文字的文本不得弹出翻译卡片。
2. 明确区分离线词典/术语查询与在线整句、整页翻译。关闭在线能力时不得发起网络请求。
3. `capsuleEnabled` 在当前页面即时生效，关闭时销毁胶囊实例，重新打开时立即挂载。
4. 提供用户术语的 CSV/JSON 导入、导出、搜索、编辑、删除和清空能力。
5. 内置通用学术与统计、计算机与 AI、材料与工程、医学与生命科学、经济与社会科学五个入门术语包。
6. OpenAI 兼容 API 与 DeepL 必须支持参数校验、连接测试、严格选路和可理解的错误反馈。

## 架构

### 术语服务

新增纯 JavaScript `GlossaryService`，同时支持浏览器全局和 CommonJS 测试环境。术语数据使用 `{ source, target }` 记录，源词归一化为小写、折叠空白。用户术语保存在 `chrome.storage.local`，内置术语包随扩展发布。

匹配采用最长短语优先并尊重英文词边界。优先级为：

1. 用户术语
2. 已启用的领域术语包
3. 默认启用的通用学术术语包
4. 原有离线单词词典
5. 当前选择的在线引擎

整句翻译时先保护公式，再将术语替换为 `PDTERM_n` 占位符；在线翻译完成后先恢复指定中文术语，再恢复公式。术语库每次修改均递增版本号。

### 翻译引擎

新增可测试的翻译引擎适配层。公共引擎、OpenAI 兼容接口和 DeepL 通过统一结果结构返回：

```js
{
  success: true,
  translation: '译文',
  source: 'OpenAI 兼容 API',
  engine: 'openai'
}
```

失败结果包含稳定错误码和面向用户的信息，但不得包含 API Key。用户选择 OpenAI 或 DeepL 后严格使用该引擎；认证失败、限流、模型不存在、响应格式错误和超时均直接返回，不静默降级。公共免费引擎只在明确选择 `default` 时使用。

API Key 迁移并保存到 `chrome.storage.local`。Endpoint 和模型等非敏感偏好保留在同步存储。连接测试绕过缓存并翻译固定短句，只有真实收到有效译文才显示成功。

缓存键由引擎、Endpoint、模型、术语版本和原文共同组成，避免切换配置后返回旧引擎结果。

### 页面与设置状态

`DictService` 提供统一的英语源文本判断：文本必须包含至少两个拉丁字母，且不得含中日韩统一表意文字。划词和整页候选段落复用该判断。

关闭在线翻译时：

- 本地词典或术语命中仍正常显示。
- 本地未命中时显示“本地词典与术语库未收录”。
- 整页翻译不排队、不发请求，显示“整页翻译需要在线引擎”。

`PaperBilingualManager` 监听 `chrome.storage.onChanged`。`capsuleEnabled` 变为 `false` 时移除 host 并将管理器引用清空；变为 `true` 且当前站点未禁用时立即创建新胶囊。

### 设置界面

翻译引擎区域增加配置校验、测试连接按钮和状态反馈。OpenAI 兼容接口要求 API Key、Endpoint 与模型；DeepL 要求 API Key，Endpoint 可留空使用官方地址。

术语区域提供：

- 内置术语包复选项，其中通用学术包默认启用。
- UTF-8 CSV 和 JSON 文件导入。
- 搜索、添加、编辑、删除、清空和导出。
- 导入冲突时用户术语覆盖同源旧记录，并显示新增、更新和忽略数量。

CSV 格式为 `source,target`，支持带引号字段；JSON 格式为对象数组，例如：

```json
[
  { "source": "retrieval-augmented generation", "target": "检索增强生成" }
]
```

## 错误处理

- 导入文件格式错误时不覆盖已有术语，并指出行号或记录序号。
- API HTTP 状态映射为认证失败、权限不足、限流、模型/Endpoint 不存在或服务异常。
- 网络请求统一设置超时并确保清理计时器。
- Chrome 消息通道错误和存储错误显示在当前操作区域，不只写入控制台。
- 用户关闭在线翻译属于配置状态，不显示为网络故障。

## 测试

测试先于实现，覆盖：

- 纯中文、中英混合和英文文本的触发判定。
- CSV/JSON 导入、冲突覆盖、最长术语匹配和占位符恢复。
- 用户术语及内置术语包的优先级。
- OpenAI 和 DeepL 请求格式、成功响应、HTTP 错误、超时和严格不降级。
- 缓存按引擎、模型和术语版本隔离。
- 关闭在线翻译后整页流程不发送消息。
- `capsuleEnabled` 关闭与重新打开时即时销毁和重建。
- 原有 68 项测试、诊断测试、JavaScript 语法检查全部通过。

## 非目标

- 不在扩展内运行大型神经机器翻译模型；真正的离线整页机器翻译会显著增加安装体积和内存占用。
- 不承诺内置术语包覆盖所有学科；它们是可审校、可扩展的入门包，用户术语始终拥有最高优先级。
