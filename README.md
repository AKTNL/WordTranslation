## ✨ 为什么选择 PaperDict

在阅读 arXiv、IEEE、ACM、Nature、Science 等学术文献或本地 PDF 论文时，传统翻译工具常面临以下痛点：
1. **频繁跳转打断思考**：每次遇到生词都要复制粘贴到独立词典软件中，思路容易被打断。
2. **强制秒弹遮挡文字**：鼠标划词常常只是为了复制或高亮，卡片秒弹遮挡后文，极度打扰。
3. **缺少学术生词沉淀**：查完生词就忘，缺乏生词本与 Anki 记忆卡片导出。
4. **论文 PDF 跨行断词灾难与多栏混排**：学术论文多为双栏排版，跨行连字符与左右栏混排导致查词/速读错乱。
5. **宿主网页样式污染与夜间刺眼**：外部网站 CSS 污染导致卡片变形，缺乏暗色主题夜间极度刺眼。

**PaperDict 彻底解决了上述问题，提供克制、可控、零配置、无缝集成的极致论文阅读体验！**

## 🌟 核心功能与亮点

- 🕊️ **克制优雅的划词触发（三大模式自由切换）**：
  - **划选直接秒弹（默认）**：松开鼠标瞬间即出释义卡片，搭配智能防抖与防误触；
  - **轻量悬浮图标**：划选后仅在光标旁浮现精致小图标，点击才展开释义卡片，绝不遮挡正文与打扰复制；
  - **快捷键触发**：按住 `Alt` 键划词才查词，平时划选纯净复制。
- 📌 **卡片自由拖拽与钉住（Pin）**：
  - 悬浮释义卡片支持任意拖拽，不遮挡正文；
  - 支持图钉钉住（Pin），点击外部不关闭，方便对照研读与论文写作。
- 📚 **内置 15,600+ 学术离线高频词典**：
  - 精选涵盖考研、CET-4/6、GRE、TOEFL、IELTS、AWL 及计算机/学术词汇，断网秒出，零配置。
- 🧠 **可控的论文术语库**：
  - 默认提供通用学术与统计术语包，并可按需启用计算机与 AI、材料工程、医学、生物及经济社科术语包；
  - 支持导入、编辑和导出 UTF-8 CSV / JSON 自定义术语，用户指定译法优先于内置词库和在线引擎；
  - 整句与整页翻译会先保护专业术语，翻译完成后再恢复指定中文译法，保持全文术语一致。
- ⭐ **论文生词本与 Anki / CSV 导出**：
  - 查词卡片一键点击 ⭐ 收藏至本地生词本，自动记录查词历史；
  - 支持一键导出为 **Anki 记忆卡片格式（TXT）** 或 **CSV 表格**，形成学术记忆闭环。
- 🚫 **站点黑名单与胶囊隐藏**：
  - 支持一键“在当前网站禁用 PaperDict”，避免在日常网站或在线文档中打扰；
  - 常驻右侧的“论文速读”胶囊支持一键彻底隐藏。
- 🌙 **全界面自适应深色模式（Dark Mode）**：
  - 释义卡片、Popup 面板、PDF 阅读器全面适配深色模式，夜间阅读温和不刺眼。
- 🤖 **支持自定义学术 API（DeepL / OpenAI 兼容大模型）**：
  - 除了免费公共引擎外，支持在 Popup 中配置 DeepL、OpenAI、DeepSeek、Kimi、智谱 GLM 等兼容接口；
  - 提供真实连接测试与认证、限流、模型错误反馈。选定自定义引擎后严格使用该引擎，失败时不会静默切换为公共引擎。
- 🚀 **PDF 阅读器虚拟化按需渲染与双栏排版优化**：
  - 采用视口虚拟化加载，50+ 页长论文秒开不卡顿；
  - 缩放平滑保留阅读进度与滚动位置；
  - 算法自动识别双栏排版，彻底解决跨栏文本混排乱套问题。
- ✂️ **PDF 跨行连字符自动智能修复（De-hyphenation）**：
  - 自动识别并合并论文跨行连字符断词（如 `experi-` 换行 `mental` 自动合并为 `experimental`）。
- 🧩 **智能时态、复数与所有格还原**：
  - 识别学术复数（`hypotheses` → `hypothesis`）、过去分词（`formulated` → `formulate`）及所有格（`model's` → `model`）。

## 🎯 深度学术阅读与笔记工作台 (v2.3 重磅升级)

### 1. 4 色学术高亮与就地思考笔记 (Highlight + Note)
* **纯色极简标注**：查词卡片内置 4 种经典学术高亮色块（黄/绿/蓝/粉），无冗余文字堆砌，轻点即标；
* **拒绝重复嵌套与长度失控**：系统内置高亮锚点去重机制，选区切换颜色或保存笔记时**就地原地更新**，杜绝标签嵌套或文字变长；
* **点击高亮即出笔记详情**：点击页面中的高亮段落，卡片稳定悬停展示对应思考笔记，点击空白处自动收起，彻底杜绝一闪而过的问题；
* **多端一键导出 Markdown (.md)**：
  - **就地卡片**：笔记输入框右侧提供 `导出 MD`，一键导出当前论文全部笔记；
  - **常驻胶囊**：点击展开右侧悬浮胶囊，底部直接集成 `导出笔记`；
  - **扩展弹窗与 PDF 阅读器**：提供统一的【论文笔记】管理面板，支持一键导出完美兼容 **Obsidian / Notion / Logseq** 的结构化知识库文件。

### 2. 论文专属术语/缩写释义库 (Paper-specific Glossary)
* **痛点根治**：在长篇论文中，作者常在第 2 页定义专属缩写（如 `LoRA`、`DPO`、`RoPE`、`ViT`），读者读到后文极易遗忘；
* **自动全篇嗅探**：页面加载与 PDF 解析时，算法自动提取混合大小写学术缩写、全称及首现定义例句；
* **最高优先级命中**：划选或查词时，系统优先比对本篇论文专属术语表，以醒目标签呈现 `[论文专属定义]` 及**出处原文例句**；
* **全篇术语抽屉**：PDF 阅读器顶部常驻 `术语表` 按钮，一键展开全篇专有名词列表。

### 3. 正文引用卡片 [12] 悬浮预览 (Citation Hover Card)
* **痛点根治**：读到正文 `[1]` 或 `[12, 13]` 时，无需再一路滚到文末翻找参考文献再滚回；
* **原地秒级浮现**：划选或点击引用标记（如 `[1]`、`[2]`、`[1, 2]`、`[3-5]`），就地弹出结构化文献预览卡片；
* **一站式学术跳转**：卡片中清晰呈现论文标题、发表年份、作者信息，并提供 **[Google 学术]**、**[arXiv]**、**[DOI]** 官方直达链接。

### 4. Semantic Reader 式上下文术语深度解析 (AI 导读)
* **专业语义推演**：针对一词多义的学术概念（如强化学习/LLM 采样中的 `temperature`、注意力机制中的 `disentangle`），点击卡片动作栏的 **`[导读]`** 按钮；
* **双要素解析**：结合论文主标题与前后 300 字符上下文段落，精炼输出：
  1. `[学科概念]`: 在该研究领域的准确学术定义；
  2. `[本文语境]`: 在本文该段落/模型中的实际作用与直观理解。

### 5. 翻译缓存强化与请求实时取消 (Cache & Abort)
* **毫秒级防抖与请求取消**：引入全局 `AbortController` 追踪池，快速切换划选或关闭卡片时，正在进行的网络传输瞬间中止，杜绝旧请求覆盖新单词的竞态闪烁；
* **同一查询并发合并**：就地双语或阅读器快速滚动时，对相同句子的请求自动 Promise 合并复用，大幅减少网络拥堵与 API Token 消耗。

### 6. 全向 360° 自由平移拖拽与清爽极简界面
* **全向自由平移**：右侧速读悬浮胶囊支持 2D 平面 360° 自由拖拽摆放（不再受限于竖直单向），停靠随心；
* **清爽极简设计**：全界面杜绝花哨 emoji，统一采用清爽紧凑的学术排版；卡片头部动作清晰简明（`导读`、`收藏`、`固定`、`复制`、`关闭`）。

## 🎯 人性化交互与学术生词本 (v2.2 功能)

### 1. 划词触发模式（可在扩展弹窗自由配置）
* **【划选直接秒弹】（默认）**：鼠标松开瞬间立即弹出卡片，适合追求极速查词的用户。
* **【轻量悬浮图标】**：划选英文文本后，光标右上方仅浮现一个半透明精致小蓝标，点击图标才展开查词卡片，适合需要大量复制文字的用户。
* **【快捷键触发】**：按住键盘 `Alt` 键划词才弹出，平时划词只作复制与阅读使用。

### 2. 卡片拖拽与钉住
* 鼠标按住卡片头部即可拖动到屏幕任意空白位置；
* 点击卡片右上角的 📌 图钉按钮即可“钉住”卡片，点击网页空白处卡片不会消失。

### 3. 论文生词本与 Anki 导出
* 查词卡片右上角点击 ⭐ 即可将生词保存到本地生词本；
* 打开扩展弹窗的【生词本】选项卡，可浏览收藏词汇，并支持一键导出为 **Anki 卡片文本** 或 **CSV**。

### 4. 站点黑名单与胶囊隐藏
* 在弹窗中可一键开关“在此网站启用 PaperDict”；
* 悬浮速读胶囊底部提供了“隐藏胶囊”和“在此站禁用”按钮；从设置重新打开胶囊会在当前页面立即生效，无需刷新。

### 5. 离线能力与整页翻译说明
* “离线学术词典”表示当前单词或术语由本地词库命中，不代表浏览器内置了离线机器翻译模型；
* 单词和已收录术语可完全断网查询，整句和整页翻译需要启用公共引擎、OpenAI 兼容接口或 DeepL；
* 关闭“在线翻译”后，PaperDict 不会发送翻译请求，本地未命中时会给出明确提示。

### 6. 自定义术语格式

CSV 文件使用 `source,target` 两列：

```csv
source,target
retrieval-augmented generation,检索增强生成
confidence interval,置信区间
```

JSON 文件使用对象数组：

```json
[
  { "source": "large language model", "target": "大语言模型" }
]
```

## 🚀 极速安装与部署指南

PaperDict 采用原生 JavaScript 实现，**零构建依赖**，代码透明清晰，直接加载即可使用。

### 方式一：直接下载安装包（最推荐，小白友好 ⭐⭐⭐⭐⭐）
1. 前往 GitHub 的 **[Releases 最新发布页](https://github.com/AKTNL/WordTranslation/releases)**。
2. 下载最新的 **`paperdict-v*.zip`** 压缩包，并解压到你的电脑中。
3. 参考下文在 Chrome 或 Edge 中加载解压后的文件夹即可！

---

### 方式二：通过 Git 克隆源码使用
```bash
git clone https://github.com/AKTNL/WordTranslation.git
```

### 2. 在 Google Chrome 中加载
1. 打开 Chrome 浏览器，在地址栏输入并访问：
   ```text
   chrome://extensions/
   ```
2. 打开右上角的 **「开发者模式」(Developer mode)** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」(Load unpacked)** 按钮。
4. 在弹出的文件选择器中，选中本项目中的 **`extension`** 文件夹。
5. 安装完成！浏览器右上角扩展栏会出现 PaperDict 图标。

> ⚠️ **重要设置（本地 PDF 必开）**：  
> 若需要在浏览器中阅读本地下载的 PDF 论文，请在 `chrome://extensions/` 找到 PaperDict，点击 **「详细信息」**，勾选 **「允许访问文件网址」(Allow access to file URLs)**。

### 3. 在 Microsoft Edge 中加载
1. 打开 Edge 浏览器，地址栏输入并访问：
   ```text
   edge://extensions/
   ```
2. 开启左侧菜单底部的 **「开发人员模式」**。
3. 点击顶部的 **「加载解压缩的扩展」**。
4. 选择本项目中的 **`extension`** 文件夹即可。

## 📄 论文 PDF 阅读与划词解决方案

> **技术背景**：Chrome 和 Edge 内置的 PDF 查看器底层是 Chromium 闭源插件（`<embed type="application/pdf">`），浏览器官方出于安全机制，**禁止外部扩展程序向默认 PDF 插件内直接插入悬浮卡片或直接捕获文本划选事件**。

为了保障用户在阅读 PDF 论文时的完美体验，PaperDict 提供了 **3 种互补的划词方案**：

### 方案 A：使用内置【学术 PDF 阅读器】（体验最佳 ⭐⭐⭐⭐⭐）
* **阅读本地论文**：点击扩展图标 → 点击 **「打开学术 PDF 阅读器」**，直接将电脑里的论文 PDF **拖入窗口**，即可享受全功能划词即弹、断词修复与语音朗读。
* **阅读在线论文（arXiv 等）**：扩展默认启用了“自动在阅读器中打开 PDF”，点击任何学术 PDF 链接（如 arXiv 论文）会自动无缝转入专属阅读器。

### 方案 B：在 Chrome 自带 PDF 界面中【一键转入】
* 如果你已经在 Chrome 原生窗口中打开了一篇 PDF 论文，点击右上角 PaperDict 图标，顶部会自动弹出引导条：
  > 📄 **当前标签页为 PDF 论文**  
  > 点击按钮 **`在 PaperDict 阅读器中打开 (开启划词即弹)`** 即可瞬间切换。

### 方案 C：在 Chrome 自带 PDF 中【右键划选秒查】
* 如果临时不想切换阅读器，只需在原生 PDF 页面划选单词，**点击鼠标右键**，选择 **「PaperDict 划词翻译」**，即可弹出独立查词窗口秒出释义。

## 🛠️ 技术架构与实现原理

```
[ 学术网页 / PDF 阅读器 ]
          │ (鼠标双击 / 划选文本)
          ▼
   [ content.js ]
          │
          ├──> 1. dict_service.js 清洗文本
          │     ├── PDF 跨行断词合并: /(\w+)-\s*\n\s*(\w+)/ -> $1$2
          │     ├── 过滤纯数字 / 引用标签 [1] / 符号
          │     └── 词形与时态还原 (hypotheses -> hypothesis)
          │
          ├──> 2. 本地离线词典检索 (academic_dict.js)
          │     ├── O(1) 毫秒响应
          │     └── 成功命中 -> 格式化音标与词性释义
          │
          └──> 3. 未收录词 / 长难句 -> background.js (Service Worker)
                ├── MyMemory / Google 在线翻译异步并发与容灾兜底
                └── 优雅 Loading 骨架态填充
          │
          ▼
   [ Shadow DOM 隔离卡片 ] (挂载至 document.body)
          ├── 物理 CSS 隔离，防止宿主网站排版污染
          ├── 真人语音朗读播放 (Youdao Voice + Web Speech TTS)
          └── 一键快速复制生词释义
```
